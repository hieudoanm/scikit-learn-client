# skl — Animation

_Part of [07-ui-ux-design.md](../../07-ui-ux-design.md)._

- Button loading spinner only.
- The stepper does not animate in a loop.
- No celebratory confetti on train success.
- Transitions are ≤ 150 ms and limited to `transition-colors`.
- `prefers-reduced-motion: reduce` disables non-essential animation and smooth scrolling.
