# US-004: Start a training job

## User Story

**As a** practitioner,
**I want to** start training without waiting for fit in the browser,
**so that** the UI stays responsive.

## Acceptance Criteria

- Given a valid mapping and algorithm, when I submit, then I receive `202` with `jobId` and `status=queued` in under 300 ms p95 (NFR-002).
- Given the same `Idempotency-Key` and payload twice, when I submit, then the second response is the original `202` body.
- Given the same key and a different payload, when I submit, then `409 IDEMPOTENCY_KEY_EXISTS`.

- **Method:** POST
- **Path:** `/api/v1/jobs`

### Priority

P0

### Requirements

FR-030, FR-031
