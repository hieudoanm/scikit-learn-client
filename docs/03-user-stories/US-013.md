# US-013: Train with partial labels

## User Story

**As a** practitioner,
**I want to** train a classifier when only some rows have labels,
**so that** I can use unlabelled rows instead of discarding them.

## Acceptance Criteria

- Given a CSV whose label column is empty for some rows, when I choose Semi-supervised and a label column, then job create succeeds.
- Given fewer than 10 labelled rows, fewer than two classes, or a class with one labelled row, when I submit, then `400 INSUFFICIENT_LABELS`.
- Given a completed semi-supervised job, then metrics are computed on held-out labelled rows only and include `labelledRows`, `unlabelledRows`, and `iterations`.
- Given a completed job, then the ONNX model predicts the original class labels and matches the fitted self-training wrapper.
