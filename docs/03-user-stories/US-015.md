# US-015: Detect anomalies without labels

## User Story

**As a** practitioner,
**I want to** flag unusual rows without a target column,
**so that** I can triage outliers and export a reusable detector.

## Acceptance Criteria

- Given a CSV with no label, when I choose Anomaly detection, map X, and accept `auto` contamination, then job create succeeds.
- Given `contamination` outside `(0, 0.5]`, when I submit, then `400 INVALID_HYPERPARAMETERS`.
- Given a completed anomaly-detection job, then `anomalyCount`, `anomalyRate`, `scoreMean`, and `scoreStd` are returned.
- Given a completed job, then ONNX labels (`1` inlier, `-1` outlier) and scores match sklearn.
