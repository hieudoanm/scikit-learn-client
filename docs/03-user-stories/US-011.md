# US-011: Handle training failures

## User Story

**As a** practitioner,
**I want to** see a failed job with a stable error code,
**so that** I can change mapping or algorithm and retry by creating a new job.

## Acceptance Criteria

- Given a dataset that cannot be fitted (for example a single class in classification after split), when training fails, then `GET` returns `200` with `status=failed` and `error.code`.
- Jobs are not restarted in place; I create a new job.
- No ONNX artefact row exists for a failed job.
