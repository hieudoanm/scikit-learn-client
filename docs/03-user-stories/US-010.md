# US-010: Handle invalid CSV uploads

## User Story

**As a** practitioner,
**I want to** understand why a file was rejected,
**so that** I can fix the CSV.

## Acceptance Criteria

- Given a file without a header row, when I upload, then `400 VALIDATION_ERROR` names the rule.
- Given a non-UTF-8 file, when I upload, then `400 VALIDATION_ERROR`.
- The UI shows the API `message` and does not show a stack trace.
