# US-001: Upload a CSV

## User Story

**As a** practitioner,
**I want to** upload a CSV with a header row,
**so that** skl can infer columns for mapping.

## Acceptance Criteria

- Given a UTF-8 CSV ≤ 10 MiB with a header and at least one data row, when I upload it, then the API returns `201` with `datasetId`, `sha256`, `columns`, and `rowCount`.
- Given an empty file, when I upload it, then I receive `400 VALIDATION_ERROR`.
- Given a file larger than the cap, when I upload it, then I receive `413 UPLOAD_TOO_LARGE`.

## Technical Implementation Details

- **Method:** POST
- **Path:** `/api/v1/datasets`
- **Body:** `multipart/form-data` field `file`

### Test Cases

1. Valid sample CSV → 201
2. Empty → 400
3. Oversize → 413
4. Original filename not used as storage path
