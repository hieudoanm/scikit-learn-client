# US-009: Browse job history

## User Story

**As a** practitioner,
**I want to** see previous jobs,
**so that** I can re-download artefacts without retraining.

## Acceptance Criteria

- Given several jobs, when I `GET /api/v1/jobs`, then results are newest first and paginated.
- Given I open a historical completed job, when I download ONNX, then the original file is returned.
