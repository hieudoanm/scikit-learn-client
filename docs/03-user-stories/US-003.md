# US-003: Choose a task and model

## User Story

**As a** practitioner,
**I want to** pick a task and an allow-listed algorithm,
**so that** I control which estimator is fitted.

## Acceptance Criteria

- Given `GET /api/v1/algorithms`, when I load the new-job page, then I only see algorithms for the selected task.
- Given the five task types, when I select each one, then the algorithm list is filtered and only compatible entries remain.
- Given an unknown `algorithmId`, when I create a job, then `400 UNKNOWN_ALGORITHM`.
- Given `taskType=regression` and `logistic_regression`, when I create a job, then `400 TASK_ALGORITHM_MISMATCH`.
- Given an out-of-range hyperparameter, when I create a job, then `400 INVALID_HYPERPARAMETERS`.
