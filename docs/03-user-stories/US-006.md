# US-006: Download the ONNX model

## User Story

**As a** practitioner,
**I want to** download `.onnx` after a successful job,
**so that** I can use the model in another runtime.

## Acceptance Criteria

- Given `status=completed`, when I list artefacts, then exactly one `format=onnx` entry exists.
- Given that artefact id, when I GET the download URL, then I receive `application/octet-stream` with a `.onnx` filename.
- Given a failed job, when I request an ONNX artefact, then `404`.

### Priority

P0
