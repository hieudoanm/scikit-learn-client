# US-012: Monitor system health

## User Story

**As a** developer/operator,
**I want to** query liveness and readiness,
**so that** Compose and I can tell when Postgres is down.

## Acceptance Criteria

- `GET /healthz` returns `200` if the process is up.
- `GET /readyz` returns `200` when Postgres answers a ping, otherwise `503`.
- Compose `depends_on` uses these healthchecks.

### Priority

P0

### Requirements

FR-070..FR-072
