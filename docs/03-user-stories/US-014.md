# US-014: Cluster an unlabelled dataset

## User Story

**As a** practitioner,
**I want to** group similar rows without a label column,
**so that** I can explore structure in a CSV and export a clustering model.

## Acceptance Criteria

- Given a CSV with no label, when I choose Clustering, map X, and set the number of clusters, then job create succeeds.
- Given a supplied label column, when I submit a clustering job, then `400 INVALID_COLUMN_MAP`.
- Given a cluster count below 2 or greater than or equal to the row count, when I submit, then `400 INVALID_HYPERPARAMETERS`.
- Given a completed clustering job, then silhouette, Davies–Bouldin, Calinski–Harabasz, and inertia/BIC are returned.
- Given a completed clustering job, then the ONNX model's cluster labels match sklearn.
