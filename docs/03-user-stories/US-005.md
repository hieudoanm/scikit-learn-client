# US-005: Monitor training status

## User Story

**As a** practitioner,
**I want to** poll job status,
**so that** I know when export is ready.

## Acceptance Criteria

- Given a running job, when I `GET /api/v1/jobs/{jobId}`, then I see a non-terminal status from the documented lifecycle.
- Given a finished job, when I poll, then I see `completed` or `failed` and polling stops in the UI.
- Given an unknown id, when I poll, then `404 JOB_NOT_FOUND`.
