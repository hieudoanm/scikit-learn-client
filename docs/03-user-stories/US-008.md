# US-008: Review evaluation metrics

## User Story

**As a** practitioner,
**I want to** see metrics for the selected task,
**so that** I can judge whether the model is usable.

## Acceptance Criteria

- Given a classification job, when it completes, then `metrics` contains `accuracy`, `precisionMacro`, `recallMacro`, `f1Macro`.
- Given a regression job, when it completes, then `metrics` contains `rmse`, `mae`, `r2`.
- Given a semi-supervised job, when it completes, then `metrics` also contains `labelledRows`, `unlabelledRows`, and `iterations`.
- Given clustering or anomaly jobs, when they complete, then `metrics` contains the documented unsupervised scores.
- Each score is shown with a plain-language meaning and its direction.
