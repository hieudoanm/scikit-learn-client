# US-002: Map features (X) and label (Y)

## User Story

**As a** practitioner,
**I want to** choose feature columns and, when the task needs one, a label column,
**so that** the model trains on the intended target.

## Acceptance Criteria

- Given a dataset with columns `a,b,y`, when I set X=`a,b` and Y=`y`, then job create succeeds.
- Given a clustering or anomaly-detection task, when I supply no Y, then job create succeeds.
- Given Y also listed in X, when I submit, then `400 INVALID_COLUMN_MAP`.
- Given a label-required task with no Y, or an unsupervised task with a Y, when I submit, then `400 INVALID_COLUMN_MAP`.
- Given a regression task and a non-numeric Y, when I submit, then `400 INVALID_LABEL_TYPE`.
