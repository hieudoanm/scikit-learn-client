# US-007: Download optional pickle or joblib artefacts

## User Story

**As a** practitioner,
**I want to** optionally download `.pkl` or `.joblib`,
**so that** I can reload the model in Python when I need the native format.

## Acceptance Criteria

- Given a sklearn job with `exportPkl=true`, when the job completes, then a `pkl` artefact exists in addition to ONNX.
- Given a sklearn job with `exportJoblib=true`, when the job completes, then a `joblib` artefact exists in addition to ONNX.
- Given a sklearn job with `exportPkl` omitted/false and `exportJoblib` omitted/false, when the job completes, then only ONNX is listed.
- ONNX export failure still fails the job even if pickle or joblib succeeded.
